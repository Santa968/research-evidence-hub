本表是 GitHub Issue 的内容底稿。用户已确定平台两人、benchmark 两人，具体账号尚未提供。表中的 A–F 是原工作包标记，不再对应六个待分配人员。当前平台先做需求与方案，T02/T04/T05/T06/T09/T10/T13 的工程实现暂缓；P1 必须在 P0 可演示后开始。

平台准备阶段先评审 [前端设计约束与参考](前端设计约束与参考.md)、[知识库与模型接入方案](知识库与模型接入方案.md) 与 [资料清单](资料清单.md)。旧时间表不构成现在启动工程的指令。

## T01 模型与额度接入验证

交付一张不含凭证的能力表：区分看山工作台补贴与开放平台 Access Secret，记录可外部调用性、模型 ID、消息上下文、限流、额度与部署用途。当前先完成公开文档核查；真实凭证可用后再做最小文本和自有证据问答验证。benchmark 所需的原生工具调用、embedding 与 judge 由评测组另行验证，网站答疑不以这些能力为前提。

完成条件：说明哪些能力已实际验证、哪些仅文档描述；给出网站与评测的可行路线。仅能在看山桌面工具里使用的额度，不能当作已具备通用 API。

## T02 网站工程与首次部署

按技术约定建立 Next.js / TypeScript 应用，锁定依赖，提供 `.env.example` 与实际启动命令；建立知识库、问答、实验三个入口。先部署一个可访问版本。

完成条件：干净检出可安装和构建；游客访问可见导航；服务端变量可正确注入且不进入浏览器 bundle。

## T03 审核资料并完成 8 条知识内容

从资料清单整理概念、benchmark 和复现指南；优先交 3 条，随后补到 8 条。核对关键数字的原始来源与版本，删去无依据的领先性断言。设计 15 题问答验收集。

完成条件：8 条都有来源、日期、核验状态；不包含未经允许公开的附件全文；15 道题有参考证据或预期拒答原因。

## T04 知识库浏览与搜索

完成列表、分类、关键词搜索、正文及来源定位，覆盖空结果、无条目和手机布局。

完成条件：5 个约定关键词均命中预期内容；分类和关键词同时有效；正文来源可点击。

## T05 服务端检索、问答与引用校验

按知识片段检索后生成回答；检索为空直接说明资料不足。校验引用 ID，控制上下文、并发、输入长度和超时，错误返回统一 code。接口契约以技术约定为准。

完成条件：有依据问题有可追溯引用；无依据不编造；不能返回未审核内容、未知引用或密钥；日志仅保留脱敏诊断信息。

## T06 问答界面与引用跳转

完成预设问题、输入、请求状态、错误重试、答案和引用展示。

完成条件：连续走通一次回答、一次资料不足、一次超时/额度错误；引用可定位知识正文或 run 详情。

## T07 Benchmark 环境、样本与 3 题试跑

给 LiveMCPBench 做限时验证，必要时切 BFCL。固定上游 commit、样本清单及评分器；跑通 3 题，至少含可检查的轨迹与评分产物。

完成条件：用同一组命令能重新运行试跑；标明对官方流程的任何改动，不能把自定义小测称作完整官方复现。

## T08 正式运行、评分与实验报告

固定配置后运行目标 20 题、最低 10 个不同任务，记录全部计划 ID、失败和重试。导出 `run`、`tasks` 和脱敏事件。

完成条件：每个计划任务都有最终状态；统计可由逐题记录复算；完成一份实验结论与限制说明，并挑选至少一个可解释案例。

## T09 结果页、配置与案例详情

按 JSON 契约完成汇总表、run 详情、样本状态和案例日志。开发样例始终显示“预设演示”，发布前接入真实结果。

完成条件：页面分子分母等于实验产物；不存在的费用和 token 显示未记录；本地实测与官方引用没有混排误导。

## T10 联调、验收与发布

执行验收清单，记录设备、时间、commit、部署地址、通过/失败及修复情况。冻结版本并保留回滚方式。

完成条件：P0 验收通过或明确披露缺项；游客、手机、主流程和问答故障路径都经过检查。

## T11 海报、视频、README 与提交材料

使用大赛指定海报模板；视频控制在 3 分钟以内，按验收文档脚本录制。补齐 README 的真实部署、运行和复现步骤，核对源码与视频游客可访问。

完成条件：提交字段齐全且已保存；材料引用最终版本；视频无 token、个人资料或虚构成绩；保存提交成功凭证。

## T12 第二策略或第二模型公平对比

在已冻结任务集、相同预算和评分口径下只改变一个因素。先确认新增调用量与可用额度。

完成条件：并列报告每种配置的完整结果，公开差异与不可比项；样本太小时不宣称显著领先。

## T13 工具调用日志回放

消费真实脱敏事件，实现播放、暂停、逐步、重置，展示参数摘要、耗时和结果。无有效日志则用事件列表完成 P0。

完成条件：事件顺序与日志一致，回退/重置正常；预设动画有持续可见的演示标识，不进入统计。
